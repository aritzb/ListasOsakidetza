# Blazor UI Skill

Use this skill when editing pages, layouts, or styling in the Blazor UI.

## Principles

- Keep markup readable and component-oriented.
- Prefer Bootstrap utilities before adding custom CSS.
- Use `app.css` for reusable visual rules.
- Preserve responsive behavior on narrow screens.

## Common Targets

- `Components/Layout/MainLayout.razor`
- `Components/Layout/NavMenu.razor`
- `Components/Pages/*.razor`
- `wwwroot/app.css`

## Validation

- Check mobile behavior.
- Verify table readability and spacing.
- Keep loading and empty states explicit.
